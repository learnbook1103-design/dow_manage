# DOW Manage 리팩토링 기준

## 현재 구조 기준선

| 영역 | 규모 | 현재 판단 |
| --- | ---: | --- |
| `admin.html` | 약 5,600줄 | 근태 업로드·판정·동기화·보고서 UI가 한 파일에 결합 |
| `supplement.html` | 약 2,500줄 | 직원 인증·조회·보완·달력·보고서가 결합 |
| `approval.html` | 약 2,000줄 | 결재 폼·결재선·Storage·목록 UI가 결합 |
| `shared_logic.js` | 약 650줄 | 핵심 근태 판정 로직. 브라우저 전역 함수였으며 1차로 테스트 가능하게 전환 |
| `server.js` | 약 430줄 | 로컬 Hub API와 결재 API, 정적 서버가 결합 |
| `api/` | 5개 함수 | Vercel 운영 API. 로컬 `server.js`와 일부 로직이 중복 |
| `script.js` | 약 2,000줄 | `admin.html` 내장 로직과 상당 부분 중복. 현재 HTML에서 직접 로드되지 않음 |

## 모든 변경의 통과 기준

1. `npm test`: 외부 서비스 없이 실행되는 순수 로직 단위 테스트
2. `npm run test:local`: 로컬 DB CRUD·Storage·서버 API 통합 테스트
3. `npm run db:reset` 후 같은 테스트가 다시 통과할 것
4. 로컬 테스트 중 운영 Supabase와 Google Apps Script 쓰기를 호출하지 않을 것
5. 데이터 정규화·이상근태 판정 결과가 바뀌는 수정은 먼저 회귀 테스트를 추가할 것
6. 큰 HTML 파일에서 코드를 꺼낼 때는 한 기능 단위로 이동하고 같은 커밋에서 검증할 것

## 단계별 작업 순서

### 1단계 — 안전망과 설정 통합

- [x] 공통 로컬/운영 설정 모듈
- [x] 근태 공통 로직 Node 테스트 지원
- [x] 서버 유틸리티 테스트 지원
- [x] 로컬 DB·Storage 검증
- [x] 로컬 서버 health·결재 API 검증

### 2단계 — 근태 도메인 분리

- [x] 업로드 형식 판별·헤더 탐색·날짜 파싱·행 정규화를 `lib/attendance/import-normalizer.js`로 이동
- [x] 행렬형/출입 이벤트형/한 열 CSV fixture와 단위 테스트 추가
- [x] `admin.html`의 실제 업로드 경로를 새 정규화 모듈에 연결
- [x] `admin.html`에 남아 있던 호환용 정규화 함수 제거
- [x] 한국어 컬럼 별칭과 출입 로그 경계시간 규칙을 단일 모듈로 통합
- `script.js`와 `admin.html`의 중복 함수를 비교해 활성 구현 하나로 통합
- [x] HTML 진입점에서 `script.js`가 로드되지 않는 상태를 자동 테스트로 고정

현재 `script.js`는 어떤 HTML에서도 로드되지 않는다. 즉시 삭제하지 않고 이력·외부 참조를
확인할 때까지 비활성 후보 코드로 유지한다.

### 3단계 — 화면 모듈화

- Supabase 접근을 화면별 repository 모듈로 분리
- [x] 인증 세션 저장 키와 읽기·저장·로그아웃을 공통 모듈로 분리
- [x] 로그인·관리자 화면을 공통 세션 모듈로 전환
- [ ] 근태 보완·결재·포털 화면을 공통 세션 모듈로 전환
- 알림, escape 처리, 날짜 포맷 중복 제거
- 인라인 이벤트 핸들러를 명시적 초기화 함수로 이동

### 4단계 — 서버/운영 API 통합

- 로컬 `server.js`와 `api/hub-*.js`의 공통 프롬프트·메시지 변환 로직 공유
- 파일 저장소만 로컬 파일/GitHub adapter로 분리
- 요청 검증과 에러 응답 형식 통일
- 외부 API는 주입 가능한 client로 감싸 단위 테스트에서 호출 금지

### 5단계 — 성능과 정리

- 대량 근태 처리에서 반복적인 `find`, 날짜 파싱을 Map/Set 인덱스로 교체
- 1,000행 제한을 고려한 Supabase 페이지 조회 유틸리티 통합
- 디버그 로그를 환경별 logger로 교체
- 사용되지 않는 `script.js`는 참조 검증 후 제거
- 번들/정적 자산 로딩과 캐시 정책 정리
